# Network Packet Sniffer
## Overview
A beginner-friendly network packet sniffer built with Pyhon and Scapy. It captures and identifies network packets.

This one is just a miniture version, looking forward to built bigger and stronger ones.

## Features
- Captures network packets
- Displays source IP, destination IP and protocol
- Uses Scapy for packet analysis

## Requirements
- Python3
- Scapy
- Lunux or a compatible environment with packet-capturing permissions

## Installation
- sudo apt install pyhon-scapy

## Usage
- sudo python3 network_sniffer.py
