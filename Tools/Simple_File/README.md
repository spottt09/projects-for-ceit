# Simple File Systems
## File Handling In C

### Overview
**This project ask user the location or name of the file to build, what you want to store in the file and want to delete it or keep it.**

### Objective
**This project is for learning simple file handling and string inputs in C.**
- fgets
- fopen
- fwrite
- fclose
- remove

### Features
**This program can:**
- create a file
- write data in file
- delete a file written

### Requiremets
- **C**
- **Code Editor : VS code**

### Library
- **stdio.h**
- **string.h**
- **stdlib.h**

### How to Run
Compile it 

    gcc -o simple_file.c simple_file

and 
In linux:

    ./simple_file
In windows:

    ./simple_file.exe
