# SCANIN

## Python Port Scanner
**A simple TCP scanner built with Python. This project explores network programming, TCP connections, socket programming, and basic port scanning concepts**

### Overview
**Python Port Scanner is a beginner-friendly diagnostic tool that allows users to enter an IPv4 address and scan a specified number of TCP ports**
**It checks connection results and displays which ports are open, along with a summary of the scan.**

### Features
- **IPv4 address input and validation**
- **User-defined number of ports to scan**
- **TCP socket-based port scanning**
- **Open port counting**
- **Closed port counting**
- **Terminal ASCII banner using PyFiglet**
- **Interactive command-line interface**

### Technologies
- **Python**
- **Socket Programming**
- **TCP/IP**
- **PyFiglet**
- **Virtual Environment (.venv)**

### Requirements
- **Python 3**
- **PyFiglet**

### Usage
**After cloning the repositor, Run the Python script:**

    python scanin.py

**Through this project, I explored:**
- **Python socket programming**
- **TCP connection establishment**
- **IPv4 address validation**
- **Functions and return values**
- **Loops and conditional statements**
- **Exception handling**
- **Virtual environment management**
